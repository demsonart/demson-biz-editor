# demson-biz-editor

Самостоятельный навык Codex для разработки и редактирования бизнес-книг на русском языке: от концепции и структуры до проверки аргументов, источников, кейсов и расчётов.

Не содержит рукописей, клиентских материалов, секретов или данных проекта «Счёт по делу». Сам навык и его документация не включаются в книгу.

## Установка в Codex

Попросите встроенный `skill-installer` установить навык из репозитория `demsonart/demson-biz-editor`, путь `.` с именем `demson-biz-editor`.

Для установки через поставляемый с Codex скрипт:

```sh
python3 ~/.codex/skills/.system/skill-installer/scripts/install-skill-from-github.py \
  --repo demsonart/demson-biz-editor --path . --name demson-biz-editor
```

После установки навык доступен со следующего хода. Если текущая среда не обновляет список навыков, откройте новый чат.

## Примеры

- `$demson-biz-editor Проверь структуру книги для владельцев малого бизнеса. Найди повторы и пробелы.`
- `$demson-biz-editor Отредактируй приложенную главу, сохрани мой голос. Отдельно перечисли неподтверждённые факты.`
- `$demson-biz-editor Проверь расчёт окупаемости в главе и объясни, каких исходных данных не хватает.`

## Файлы

- `SKILL.md` — точка входа и рабочий процесс.
- `agents/openai.yaml` — название и пример вызова в интерфейсе Codex.
- `references/editorial-rules.md` — редакционный стандарт.
- `references/fact-checking.md` — проверка фактов и чисел.

Навык не устанавливает фоновые процессы и не публикует материалы автоматически. Проверка структуры файлов не подтверждает качество конкретной рукописи; фактическая проверка зависит от предоставленных материалов и доступных источников.
